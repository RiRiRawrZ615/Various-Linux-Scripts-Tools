### Display/FS/Misc Tools

## 🚀 NTFS Force Mount
This utility performs an NTFS Force-Mount sequence. It clears the "dirty" bits on the drive using `ntfsfix` and removes the Windows hibernation file to ensure the drive mounts with full read/write permissions.

## 📺 Display Resolution Toggle
A quick utility to toggle your primary monitor resolution between 4K and 1080p.

## 🪟 Windows Boot
A one-click reboot tool for most dual-boot setups that allows you to jump directly to the Windows partition on your next reboot.

**Note:** The EFI boot index is hardcoded within the script and must be changed to match your specific system configuration.
